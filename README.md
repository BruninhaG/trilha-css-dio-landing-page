# 💻 Trilha de CSS da DIO - Landing Page

Este projeto foi desenvolvido como parte do desafio da **Trilha de CSS da DIO**.  
O objetivo é criar uma **Landing Page institucional** responsiva e estilizada com HTML e CSS, utilizando uma paleta de cores vibrante inspirada no estilo **neon/vaporwave**.

## 🚀 Tecnologias utilizadas
- **HTML5**
- **CSS3**

## 🎨 Layout

A página contém:
- Um **banner principal** com gradiente e botão de inscrição.  
- Seção **“O que vou aprender?”** com módulos e cores destacadas.  
- Frase inspiradora **“TRANSFORME O MUNDO COM A GENTE”** com efeito gradiente.  
- Seção **“Desafios profissionais”** com imagem centralizada e animação suave.  
- **Rodapé** com logotipo da DIO e créditos.

## 📄 Como executar o projeto
### ☁️ Clonar o repositório:
1. Clone o repositório em seu ambiente local, você pode fazer isso executando o seguinte comando no terminal: git clone https://github.com/BruninhaG/trilha-css-dio-landing-page.git
2. Acesse o projeto: Navegue até a pasta do projeto recém-clonado em seu terminal e abra o arquivo index.html em seu navegador. Por exemplo, usando o VS Code, você pode abrir o terminal integrado e executar: code index.html

### ⬇️ Fazendo o download do repositório:
1. Clique no botão "Código" neste repositório e escolha a opção "Baixar ZIP";
2. Salve o arquivo ZIP em seu computador e descompacte-o;
3. Abra a pasta descompactada e localize o arquivo index.html, dê um duplo clique nele para abrir o projeto em seu navegador.
